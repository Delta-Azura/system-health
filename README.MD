# What is raw-health ? 
raw-health is a powerful tool that aims to help you manage and understand what is happening in your machine.

The target is to be able to debug faster and smarter when a release breaks your system. 

# Features 
- A global health monitor to detect orphans, broken libs, memory consumption, disk usage, installed packages, latest updates and a dependancy tree to help you understand which update might have broke your system.
